IPYES / MPSE PUBLIC DIGITAL BUSINESS CARD - GITHUB PAGES KIT

Files:
- index.html: public digital profile landing page
- MPSE_Logo.png and IPYES_Logo.png: supplied brand logos
- IPYES_Director_Contact.vcf: iPhone/Android contact file

NEXT: publish using GitHub Pages (free option)
1. Create/sign in to a GitHub account at https://github.com
2. Create a NEW PUBLIC repository named: ipyes-digital-card
3. Upload all four files in this folder to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment, select "Deploy from a branch".
6. Select Branch: main and Folder: /(root), then Save.
7. Wait for deployment. GitHub will show the published website URL.
8. Open that URL on iPhone Safari and use Share -> Add to Home Screen.
9. Send the published URL via WhatsApp/AirDrop. A public-profile QR should be generated only after the final URL is confirmed.

PRIVACY:
You approved a public profile. The public page shows the mobile number, WhatsApp number,
both email addresses, office location, and company links. Anyone with the URL can view them.
GitHub Pages on GitHub Free requires a public repository. Do not upload passwords,
private documents, certificates, or other confidential files.

WALLET:
This kit does not include a signed Apple Wallet pass. Apple requires a Pass Type ID and
Apple-issued signing certificate associated with an Apple Developer account. The account
is not currently available, so Wallet setup is a later step.

NFC:
After the public profile URL is live, program a standard NFC tag/sticker with that URL.
The tag opens the web profile; it is separate from Apple Wallet NFC functionality.
